About the Phagwara Resilience Atlas

This version of the project was rebuilt around a synthetic dummy dataset because the original source data was not a good fit. The new dataset is generated specifically for Phagwara and designed to support map-based explanation, prediction, and classroom demonstration.

How it is built

  • Create synthetic flood records around Phagwara zones
  • Generate disaster history for earthquake, flood, heatwave, fire, storm, and industrial accident
  • Build infrastructure assets and hotspot layers for the map
  • Train flood-risk and disaster-type models
  • Serve everything through a Flask-based interactive website
